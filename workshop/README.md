Indianapolis, Indiana.

- [`images/`](images/) - Screenshots used in `workshop.md`.

The public training-platform key is `ArepasAtSHPE`; it is not an order voucher
or credential. Facilitators still need to configure its acceptance in the
external platform and supply the confirmed hosted MCP endpoint and workshop
link. See the repository [configuration and tool contract](../README.md).
